# packages/subscriptions

This directory is reserved for the `solana-program/subscriptions` upstream code.

**After the first git commit**, run:

```bash
git subtree add --prefix=packages/subscriptions https://github.com/solana-program/subscriptions.git main --squash
```

To pull upstream updates:

```bash
git subtree pull --prefix=packages/subscriptions https://github.com/solana-program/subscriptions.git main --squash
```

Do NOT commit directly to this directory. Use subtree merge for updates.
